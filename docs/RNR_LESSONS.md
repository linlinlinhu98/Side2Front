# 侧脸转正脸 · 教训与配方速查（未见图一键指南）

> 由 people.jpg 全流程试错沉淀。
> 目的：让每一张新图不再重走弯路。

## 1. 未见真人照片：一键生成

```powershell
D:\Python\python.exe tools\gen_rnr.py <图片> --strength 0.55 --seeds 7,42,123
```

- `--seeds`：pass-1 多跑几个种子（每个 ~2min），**arcface 自动选最优**
  （实测种子方差 ±0.06，单抽命中概率低；3 签约 +6min，值得）
- 全流程 ~12min（3 签）：pass-1×3 → 环带 outpaint → CodeFormer(w=0.8)
  → 青辉点压 → 两阶段比照原图回贴 → 下颌阴影
- 全帧版（上半身同构图）：`D:\Python\python.exe tools\make_full.py [512正脸] [原图]`
- 动物（猫科）：`tools\gen_frontal_refs.py cat 1 <图> result\_gen`
- 动漫：`tools\gen_frontal_ref.py <图> --auto`

## 2. 已编码的默认配方（不用记，已是默认）

| 工序 | 参数 | 教训来源 |
|---|---|---|
| pass-1 | SD1.5 img2img strength 0.55, Arc2Face id + IP-Adapter 0.5 | 0.35 是全轴唯一活点（鼻区实测） |
| 提示词 | 短后缀；长后缀冲散 Arc2Face 条件分布 | 0.035 证伪 |
| pass-2 | 环形掩码 ~80px，肤色 Reinhard mix=0.5 | 全量过冲（0.391 vs 0.410） |
| CodeFormer | w=0.8；下颌线+15px 一刀切 | w 任值都掉分=码本身份税；CF 羽化磨平下巴 |
| 发际线回贴 | 皮肤保护 dilate 21（A 版干净） | dilate 9 留头皮斑块，全帧放大读作秃斑 |
| 比照原图回贴 | 皮肤掩码必须加 Y>110 | 深棕发 58%/白花瓣 17% 被误杀出洞 |
| 右背景 | 散景 50% 恢复两遍叠加（负载语义） | 单遍接缝可见 |
| 颌下阴影 | 网格下颌曲线 14px 10% 渐弱 | 原图下颌显锐靠阴影渐变而非硬边 |
| 全帧合成 | 下颌曲线裙边+画布边框 25px 渐隐+边界焙烧+连续权重边界融合 | 凸包弦斜切/画布矩形边/硬内环三大事故 |
| 补牙 | 内唇多边形 inpaint，种子 7 | 黑洞无牙是 SD 通病 |
| 唇比例 | 垂直压缩 k=0.78 椭圆羽化形变 | SD 嘟唇先验偏厚 |
| 鼻 | E 全脸低强度重塑(0.3)+鼻梁修容+渐变软缝双孔+鼻尖压影 | 隔离 inpaint 九种畸形；硬注原图数据几何冲突 |

## 3. 失败模式速查（新图遇到直接对号）

| 症状 | 病根 | 解法 |
|---|---|---|
| 脸是面具/贴纸感 | SD 脸塑料平光 vs 真实皮肤颗粒 | 边界带连续权重融合(色调+颗粒)；全区融合=0.344 身份死刑 |
| 嘴是黑洞 | SD 不画牙 | 补牙 inpaint（内唇掩码，种子 7） |
| 唇太厚 | SD 嘟唇先验 | k=0.78 垂直压缩 |
| 鼻纽扣/下垂/单孔 | SD 幼态鼻+畸形 | E 重塑(0.3)+修容+软缝双孔；**整鼻 inpaint 必死（鹰钩/白团/电路板）** |
| 鼻孔黑环 | "填外保内"留残环 | 大孔填平后乘法渐变重画软缝 |
| 发际线秃斑 | 回贴皮肤保护太松 | dilate 21；或暗像素整区回贴（勿按暗像素选，会留斑块） |
| 背景灰板/接缝 | 矩形操作区边界叠差 | 统一为单一连续操作（散景两遍叠加/边框渐隐） |
| 下巴硬线 | 512 画布逆投矩形底边 | 画布边框 25px 渐隐 |
| mmap 段错误 (0xC0000005) | 内存压力下 safetensors mmap 页入失败 | `_read_st_slice` 缓冲 IO 逐段读（已在 gen_arc2face） |

## 4. arcface 敏感度地图（改动前先想代价）

- **嘴/鼻底/下巴几何**：极敏感（-0.03 ~ -0.15）。动之前问值不值
- **发际区**：中敏感（±0.02 噪声级）
- **脸颊纹理/颗粒**：全脸改=死刑（0.344）；边界带改≈零成本
- **亮度微调（点压/焙烧）**：≈零成本（±0.005）
- 教训：每轮改动必须测分（`tools/_similarity` 或管线内嵌），
  分数只是指标，**用户过目才是裁决**

## 5. 硬约束（勿再试）

- SD1.5 局部重画精细器官（鼻/眼）必失控——只能全脸上下文+力度 0.3
- 侧脸像素/特征硬注入正脸=几何冲突（0.297 实证）；只能软引导（IP ≤0.35）
- 全量 Reinhard 必过冲（肤色/背景两次实证）；局部自适应才安全
- 本机 16GB：SDXL/InstantID/PuLID 不可行；GPU 可用后首选
  [FastAvatar](https://github.com/TyrionWuYue/FastAvatar)
