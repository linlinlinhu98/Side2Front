1 需求背景

东南大学王洪松老师的 OpenCV-Python-Image-Processing 课程仓库中，test/4 目录上传了两张测试用图：face.png（动漫风格90度纯侧脸肖像）和 cat.jpg（虎斑猫3/4侧面照片）。竞赛测试4要求实现"侧脸转正脸"图像编辑功能：读取侧脸图像，通过交互操作将侧脸转为正脸，在GUI界面同时展示原图与转换结果，全程CPU离线运行。竞赛驱动

核心约束：全程CPU下离线运行，不得调用GPU或连接远程服务器。评分上，基本功能（图像加载、交互转换、GUI三区域布局）占60分；效果质量占40分，完成全部功能后按总运行耗时排序评分。

双模式设计的必要性：课程仓库提供的 face.png 是动漫插画风格侧脸，而非真实人脸照片。真实人脸检测器（RetinaFace）和3DMM回归模型（3DDFA_V2）均在真实人脸数据上训练，无法有效检测和回归动漫人脸的3D参数。因此系统需同时支持两种技术路线：

  • 真实人脸模式：3DDFA_V2 全自动管线 — 人脸检测 → 3DMM参数回归 → 姿态旋转 → 纹理渲染
  • 动漫人脸模式：OpenCV 交互式管线 — 手动标注关键点 → 薄板样条(TPS)变形 → 对称镜像补全 → 泊松融合

3.3 真实人脸模式：3DMM全自动管线

阶段 耗时（CPU） 处理逻辑
人脸检测 ~20-30ms 使用3DDFA_V2内置的RetinaFace-ONNX模型检测人脸边界框。支持多脸场景，默认选取面积最大者。在原图上以边框标注人脸位置。
关键点+3DMM回归 ~1.5ms 将检测到的人脸区域送入3DDFA_V2回归网络，输出68个关键点坐标和257维3DMM参数向量（含身份、表情、姿态），同时计算相机外参矩阵。
姿态旋转至正面 ~5ms 根据回归得到的yaw/pitch/roll参数，计算旋转矩阵R，将3DMM顶点云从当前姿态旋转至正面朝向（yaw=0, pitch=0, roll=0）。旋转后顶点云保留原始纹理坐标。
纹理映射与补全 ~30-80ms 使用Sim3DR渲染器对旋转后的3DMM光栅化，从原图采样颜色填充正面可见区域。对侧脸遮挡区域，采用对称镜像补全：将可见侧纹理镜像至不可见侧，再做边界融合。
边界平滑 ~10ms 对镜像补全区域与原始纹理区域的边界做泊松融合消除接缝，全图施加轻度双边滤波。
真实人脸模式的关键优势：3DDFA_V2在CPU上3DMM参数回归仅约1.35ms/图，配合内置的Sim3DR渲染模块可直接输出正面视角，无需训练模型、无需GPU、无需联网。所有权重随仓库分发。但该模型在真实人脸数据上训练，对动漫/插画风格人脸的检测和回归效果不可靠。

3.4 动漫人脸模式：交互式TPS变形管线

动漫人脸模式针对非真实人脸图像（如test/4/face.png的动漫侧脸），采用OpenCV图像变换 + 交互式关键点标注的技术路线。该路线不依赖任何深度学习模型，完全基于经典计算机视觉算法，天然适合CPU离线运行。

阶段 耗时（CPU） 处理逻辑
关键点标注 用户交互 用户在原图上点击标注面部关键点，至少需要标注以下特征点：发际线中心、眉峰、眼角（内外眦）、鼻尖、鼻翼、嘴角（上下唇）、下巴尖、耳廓上下端。系统提供默认模板点位引导，用户点击对应位置即可。也支持半自动模式：使用Canny边缘检测+形态学操作提取面部轮廓，用户在检测到的轮廓上选择关键点。
构建正面模板 ~5ms 根据标注的关键点，系统自动生成对称的正面关键点模板。以面部中线为对称轴，将可见侧的关键点镜像至不可见侧，生成正面视角的完整关键点集。中线的确定方式：取发际线中心、鼻尖、下巴尖三点拟合直线作为初始中线，用户可微调。
TPS薄板样条变形 ~50-100ms 使用薄板样条插值将原始侧脸图像warp到正面关键点位置。TPS是一种径向基函数插值方法，给定源点和目标点后，能生成平滑的二维映射场。对每个像素计算其在原图中的采样位置，使用双线性插值采样颜色。TPS柔性度参数控制变形的平滑程度：值越大变形越柔和，值越小平移越精确。
对称镜像补全 ~20ms TPS变形后，原侧脸的可见半脸已映射到正面视角的对应侧。对于另一侧（原遮挡区域），将可见侧图像以面部中线为轴做水平翻转，覆盖到不可见侧。镜像强度参数控制翻转图像的透明度叠加比例：100%为完全镜像覆盖，0%为不补全（保留灰色空洞）。
泊松融合与色调匹配 ~30-50ms 对镜像区域与原始区域的边界使用OpenCV泊松融合（cv2.seamlessClone）消除可见接缝。若原图有明显色调倾向（如动漫侧脸为黑白灰单色调），先对镜像区域做直方图匹配使其色调与可见侧一致，再做融合。关闭色调匹配时可能出现左右半脸明暗不一致。

关键点标注交互

标注方式 优先级 描述
引导式手动标注 必须 系统在原图上以半透明圆点显示关键点的预期位置模板（约15-20个点），用户依次点击每个点确认位置。已标注的点以蓝色实心圆显示，未标注的以灰色空心圆引导。支持撤销上一个点（右键或Ctrl+Z）。
半自动轮廓检测 建议 点击"半自动检测轮廓"后，系统使用Canny边缘检测+形态学闭运算提取面部外轮廓曲线，用户在轮廓上点击选择关键点位置。适合边缘清晰的动漫图像。
关键点微调 必须 所有关键点标注完成后，用户可拖拽任意点进行微调，系统实时重新计算TPS变形并在结果区域预览。
对称轴调整 建议 用户可拖拽对称轴两端微调面部中线角度，影响镜像补全和正面模板生成的对称基准。
动漫人脸模式的核心优势：完全基于OpenCV经典算法（TPS、泊松融合、边缘检测），不依赖任何深度学习模型，天然适合CPU离线。对动漫/插画风格图像效果稳定，因为不依赖人脸检测器的泛化能力。缺点是需要用户手动标注关键点，首次转换耗时包含交互时间。test/4/face.png的动漫侧脸轮廓清晰、边缘分明，非常适合Canny边缘检测和TPS变形处理。

3.5 交互参数调整（双模式共用）

用户首次转换后，可通过右侧控制面板的滑块和按钮反复调整参数。两种模式下的参数集不同，但交互方式一致：每次调整触发增量渲染，在结果区域实时更新预览。

真实人脸模式参数

控件 类型 范围/默认 交互逻辑
Yaw滑块 Range Slider -90° ~ 90°，默认0° 改变目标偏航角。0°为正面，正值右转，负值左转。系统根据3DMM参数和滑块值重新计算旋转矩阵并渲染。拖动时低分辨率实时预览，释放后全分辨率渲染。
Pitch滑块 Range Slider -30° ~ 30°，默认0° 控制俯仰角度。正值抬头，负值低头。与Yaw联动计算组合旋转矩阵。
Roll滑块 Range Slider -30° ~ 30°，默认0° 控制头部倾斜。正值右倾，负值左倾。用于微调正面姿态。
纹理补全 Toggle 默认开启 开启时遮挡区域做镜像补全+边界融合。关闭时仅显示原始可见纹理，遮挡区灰色填充。
边界平滑 Toggle 默认开启 开启时施加双边滤波和边界羽化。关闭时输出原始光栅化结果。

动漫人脸模式参数

控件 类型 范围/默认 交互逻辑
镜像强度 Range Slider 0-100%，默认80% 控制对称镜像补全的叠加比例。100%为完全镜像覆盖另半脸，0%为不补全。用户可在中间值查看镜像与TPS变形的混合效果，适合处理不完全对称的面部特征。
TPS柔性度 Range Slider 0-100%，默认50% 控制薄板样条变形的平滑程度。值越大变形越柔和、过渡越自然但可能模糊细节；值越小变形越精确、保留更多原始纹理但可能出现扭曲。拖动实时重新计算TPS系数并渲染。
泊松融合 Toggle 默认开启 开启时对镜像区域与原始区域边界做泊松融合消除接缝。关闭时直接硬拼接，边界可见明显接缝。
色调匹配 Toggle 默认开启 开启时对镜像区域做直方图匹配使色调与可见侧一致。关闭时镜像区域保留原始色调，可能出现左右明暗不一致。

4.4 双模式架构设计

class FaceFrontalizer(ABC): """抽象基类：侧脸转正脸""" @abstractmethod def convert(self, image: np.ndarray) -> np.ndarray: ... class RealFaceFrontalizer(FaceFrontalizer): """真实人脸：3DDFA_V2 全自动管线""" def convert(self, image): boxes = self.retinface.detect(image) param = self.tddfa.regress(image, boxes) vertices = self.bfm.transform(param, yaw=0, pitch=0, roll=0) result = self.sim3dr.render(vertices, image) return result class AnimeFaceFrontalizer(FaceFrontalizer): """动漫人脸：TPS + 对称镜像管线""" def convert(self, image, keypoints, mirror=0.8, tps=0.5): frontal_template = self.build_symmetric_template(keypoints) warped = self.tps_warp(image, keypoints, frontal_template, tps) mirrored = self.mirror_half(warped, mirror) result = self.poisson_blend(warped, mirrored) return result

  • 动漫模式关键点以模式专属色实心圆显示（#8A6A4A），已标注蓝色、待标注灰色空心
  • 真实模式人脸检测框以模式专属色显示（#4A6A8A）
  • 不使用渐变、阴影、毛玻璃等装饰效果，保持纯灰白色调
